# 拾知 · 15 分钟知识抽签

手机上的知识阅读工具：心理学基础、儿童发展、家庭教育、正面管教、亲子沟通、情绪与行为支持，六类各30题。

- 所有类别混合随机抽取，支持换题。
- 抽题先读“理论点”，点击“看应用实践”切换第二张卡片；以清楚为准，不设固定字数。理论依据附可核查来源，实践为建议与示例话语，不是真实个案或效果证明。
- 可使用 15 分钟计时器；笔记在自己的本子或其他应用里单独记录。
- 没有输入框和笔记；只在设备浏览器内保存已完成题目的编号。
- 不需要账号、数据库、模型密钥或服务器进程。
