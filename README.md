# 拾知 · 15 分钟知识抽签

手机上的知识题库抽取工具：六类各 30 道具体问题，共 180 题。

- 所有类别混合随机抽取，支持换题。
- 提供学习问题、中英文检索词、查阅方向、搜索入口与 15 分钟计时器。
- 没有输入框和笔记；只在设备浏览器内保存已完成题目的编号。
- 不需要账号、数据库、模型密钥或服务器进程。

使用 Safari 打开 GitHub Pages 网址，也可以添加到主屏幕。实际离线使用以设备支持为准，查阅外部资料需要联网。计时器在返回页面时更新，不发送锁屏通知；刷新页面会重置计时。

这里的关键词与查阅方向是学习线索，并不是已经核验的文献或预设答案。字体为 Instrument Sans，许可见 OFL.txt。
