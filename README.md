# 拾知 · 15 分钟知识抽签

手机上的知识阅读工具：六类各 30 个知识点，共 180 篇原创讲解。

- 所有类别混合随机抽取，支持换题。
- 抽题后直接阅读约 1500—2000 字讲解，包含解释、例子、应用、边界及参考来源。
- 可使用 15 分钟计时器；笔记在自己的本子或其他应用里单独记录。
- 没有输入框和笔记；只在设备浏览器内保存已完成题目的编号。
- 不需要账号、数据库、模型密钥或服务器进程。

正式网址：https://samuel645006417-dotcom.github.io/shizhi-15min/

使用 Safari 打开 GitHub Pages 网址，也可以添加到主屏幕。先联网打开一次并缓存完成后可离线抽题和阅读，实际离线使用以设备支持为准，打开文末外部参考链接需要联网。计时器在返回页面时更新，不发送锁屏通知；刷新页面会重置计时。

正文为原创通俗讲解，生活场景是说明性案例，参考来源用于核查与延伸阅读。心理学和家庭教育内容不用于个人诊断。字体为 Instrument Sans，许可见 OFL.txt。
